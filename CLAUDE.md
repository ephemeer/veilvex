# Veilvex — сайт агентства (Astro, static, Cloudflare Pages; Netlify — запасной)

## Стек
- Astro 7 (static output, Node ≥ 22.23.4), TypeScript strict, без UI-фреймворков. Стили — обычный CSS с токенами в `src/styles/global.css`.
- Анимации — CSS transitions/animations, WAAPI и IntersectionObserver (`src/scripts/`). Библиотек анимаций нет.
- Контент на 4 языках: английский по умолчанию (`DEFAULT_LANG = 'en'` в `src/i18n/index.ts`: `/` — английский, `/ru/`, `/az/`, `/de/` — остальные; в `astro.config.mjs` и `scripts/gen-llms.mjs` default тоже `en`; `/en/*` → `/:splat` 301 в `netlify.toml`). Ссылки строить только через `localePath`/`LANGS`/`DEFAULT_LANG`, в тестах — через `LANG_PATHS` из `tests/e2e/helpers.mjs`. Файлы `src/i18n/{ru,en,az,de}.ts` — все файлы должны соответствовать `src/i18n/types.ts` (TypeScript проверяет полноту).
- Форма заявки (POST `/api/contact`): ядро `netlify/functions/lib/contact-core.ts` не зависит от хостинга; точки входа — Cloudflare Pages Function `functions/api/contact.ts` → `netlify/functions/lib/cloudflare.ts` (KV `RATE_LIMIT`, IP из `CF-Connecting-IP`, `CONTEXT=production`, `URL` = origin запроса) и Netlify `netlify/functions/contact.mts`. Секреты только в переменных окружения (см. `.env.example`); на Cloudflare `SITE_URL` обязателен.
- Заголовки безопасности (CSP, HSTS и т. д.) и редиректы — в `netlify.toml` (единый источник); `public/_headers` и `public/_redirects` для Cloudflare генерирует из него `scripts/gen-host-files.mjs` на `prebuild` — руками не править. Инлайн-стили запрещены политикой CSP (`style=""`, `<style>` в разметке). Единственный инлайн-скрипт — `classList.add("js", mac|pc)` в `Base.astro` (класс `js` включает entrance-анимации, `mac`/`pc` выбирает подпись ⌘K / Ctrl K до первой отрисовки), его sha256-хеш прописан в CSP; любое изменение этого скрипта или новый инлайн-скрипт сломает `npm run check:csp` — пересчитывайте хеш (`printf '%s' '<текст скрипта>' | openssl dgst -sha256 -binary | base64`).
- Шрифты: сабсеты Inter для первой отрисовки (latin + cyrillic для RU, latin-ext для AZ) предзагружаются в `<head>` (`?url`-импорты в `Base.astro`), а `--font` содержит метрически совместимый `Inter Fallback` (`global.css`, три весовых диапазона с `size-adjust`), чтобы смена шрифта не меняла переносы. Заголовок hero ограничен в `em`, не в `ch`. `scroll-behavior: smooth` включается классом `html.is-loaded` после `load` (иначе браузер анимирует переход к `/#section` с верха страницы). Исключение — data-блок `<script type="application/ld+json">` (JSON-LD): он не исполняется, CSP на него не действует; `check:csp` проверяет только, что это валидный JSON без `</script`.
- Шторка кейса: клик по карточке в `Cases.astro` (при наведении/фокусе на десктопе карточка показывает мини-таблицу фактов поверх притушенной иллюстрации — transitions 200 мс, строки через 30 мс; в арене — см. ниже — шторку открывает только фронтальная карточка, а таблица фактов появляется тем же жестом наведения/фокуса) открывает `src/components/CaseSheet.astro` (`src/scripts/case-sheet.ts`) — `role=dialog` справа на десктопе (560–640px, вход `translateX(100%)` 300 мс `cubic-bezier(.32,.72,0,1)` + opacity, иллюстрация карточки перелетает в шторку — FLIP через WAAPI 320 мс, только transform; выход 180 мс без перелёта, stagger контента 300 мс по 40 мс, prev/next — сдвиг 180 мс), во весь экран на телефонах; все 12 кейсов отрендерены на сервере (`hidden`-статьи — текст виден краулерам, попадает в `llms-full.txt` и в JSON-LD как `ItemList` из `CreativeWork`); deep link `#case-N` (replaceState, язык переключается с тем же кейсом), ←/→, Esc, фокус-ловушка, `inert` (вешается после первого отрисованного кадра — пересчёт стилей всей страницы не задерживает вход панели), свой scroll lock `html.is-sheet-open` (ширина исчезнувшего скроллбара пишется инлайн-паддингом на `<html>` и `.nav`, не custom property: её запись на `<html>` заставляет Chrome пересчитать стили каждого элемента); CTA «Хочу так же» → форма с выбранной услугой через `handoffToForm` (`contact.ts`).
- SEO/GEO: JSON-LD собирается в `src/lib/jsonld.ts` из контента `t` (локализованно, стабильные `@id`). `public/llms.txt`, `public/llms-full.txt` и `public/robots.txt` генерируются из `src/i18n/*.ts` скриптами `scripts/gen-llms.mjs` и `scripts/gen-robots.mjs` на `prebuild` — руками не править. Базовый URL — `SITE_URL` (`scripts/lib/site-url.mjs`). Обложка `public/og.png` — `npm run gen:og` (`scripts/og/`, нужен Playwright; в сборку не входит).

## Команды
- `npm run dev` — сайт (+ `npm run api:dev` в соседнем терминале для формы)
- `npm run verify` — `astro check` + тесты + сборка (с `prebuild`: llms.txt/robots.txt) + `check:csp`
- `npm run gen:og` — перерендерить обложку OG после смены слогана (`hero.eyebrow` RU/EN)
- `npm run serve:secure` — раздача `dist/` с теми же заголовками, что и на Netlify (для проверки CSP локально)
- `npm run e2e` — скриншоты и проверка консоли (нужен Chromium: `npx playwright install chromium`)
- `npm run test:e2e` — браузерные e2e-тесты `tests/e2e/*.test.mjs` (Node `--test` + Playwright из `PLAYWRIGHT_MODULE` или локального пакета; требует `npm run build`; в `verify` не входит — на Netlify нет Chromium)
- `npm run qa:flicker` — детектор мерцаний/скачков (`scripts/qa-flicker.mjs` + `scripts/lib/flicker-analyze.py`, нужны Playwright и `python3` с Pillow/numpy): кадры при загрузке на медленной сети, во всех переходах состояний и при скролле → `qa/flicker/report.md`. Опционально, в `verify` не входит; после правок анимаций/шрифтов/`<head>` — прогнать. На Linux с системным Inter: `npm run qa:flicker -- --realistic-fonts`.

## Правила анимаций (кратко, подробнее в скиллах)
- Вход/выход — только ease-out (`--ease-out: cubic-bezier(.22,1,.36,1)`, для длинных маркетинговых входов `--ease-out-long: cubic-bezier(.16,1,.3,1)`), никогда ease-in.
- UI-анимации до 300 мс: нажатие 140 мс, меню 150–220 мс, модалки до 250 мс. Маркетинговые reveal-анимации 500–700 мс, без блюра.
- Ничего не появляется из `scale(0)` — старт с `scale(.95–.97)` + `opacity: 0`.
- Кнопки и любые нажимаемые элементы сжимаются на `:active` до `scale(.98)` за 140 мс.
- Только `transform`/`opacity` (+ `clip-path`); никакого `transition: all`.
- Hover-движение только под `@media (hover: hover) and (pointer: fine)`; всегда есть ветка `prefers-reduced-motion`.
- То, что пользователь видит 100 раз в день, не анимируется.
- Три «тихих» паттерна по мотивам референса (emotion-agency), по одному месту на каждый: ink-заливка манифеста «О нас» по скроллу (`src/scripts/ink.ts` + `ink()` в `src/i18n/index.ts`: слова `.w` с `--i`, один `--p` на абзаце, 38 % → 100 % в порядке чтения между 80 % и 35 % высоты экрана, без transition); затемнение соседей при hover/`:focus-within` в сетках Trust и Industries (0.65, 200 мс, без задержки; не на тарифах и FAQ); мотив «↳ + акцентное слово» в заголовке Contact (`{{слово}}` в `contact.title`, проп `motif` у `SectionHead`, глиф `i-arrow-turn` входит на 120 мс позже слова, оба 600 мс `--ease-out-long`; `reveal.ts` ждёт дочерние entrance-анимации, прежде чем снять классы). Четвёртый приём оттуда же — кнопка «Let's talk ↳»: у `.btn--swap` подпись (`.btn__label` с `data-text`, внутри `<span>`) при hover уезжает вверх за `overflow: hidden`, а её CSS-копия (`::after { content: attr(data-text) / '' }` — с пустым alt, чтобы имя ссылки не читалось дважды) въезжает снизу, 200 мс `--ease-out`, только transform/opacity, ширина кнопки не меняется; стоит на CTA hero, шапки, тарифов и 404, не на кнопке отправки формы (её подпись меняет JS). Пятый — «decode» (`src/scripts/decode.ts`): моноширинный текст с `data-decode` при первом reveal (`reveal.ts`) собирается слева направо из глифов `!$#%&*/=:;<>?{}~^_@` за 350–600 мс (≈28 мс на символ), хвост перекатывается через кадр; только на mono-тексте (ширина не меняется) и только на том, что видят один раз за сессию или раз на остановку — eyebrow секций и mono-строка «направление · теги» в арене кейсов (не на её заголовке); на время прогона видимая строка `aria-hidden`, настоящий текст — в `sr-only`-двойнике; под reduced motion текст просто стоит.
- Две «тяжёлые» витринные анимации, по одной на каждую половину страницы — поле точек в hero и арена кейсов; больше не добавлять, контраст с тихим остальным сайтом и есть эффект. Поле точек (`src/scripts/field.ts`, canvas за заголовком): курсор толкает и подсвечивает точки, при загрузке от строки с акцентом расходится волна, тап/клик по hero пускает свою. Цикл rAF работает только пока что-то движется, вне экрана и в скрытой вкладке стоит, под `prefers-reduced-motion` точки статичны. Арена (`src/scripts/arena.ts`, стили — `<style is:global>` в `Cases.astro`, порт «кольца» с emotion-agency/projects): те же `<li class="case">` расставлены CSS 3D на компактном кольце (без WebGL/canvas) — на 1440×900 карточки 200×260 через 30° на радиусе 460px, глаз в 1400px на уровне середины карточек: к зрителю обращены фронтальная и по две с каждой стороны (широкая «стена» из 11 рамок пробовалась и отвергнута владельцем); на телефонах (< 768) 150×200, 30°, 345px, 1100px — фронт и два обрезанных краями соседа. Масштаб — ширина `clamp(vw / база, 0.8, 1.3)`, ограниченная высотой (кольцо с отражением влезает в сцену); если при монтировании он < 0.6 (например 720×450), остаётся сетка, при поздних ресайзах просто не падает ниже 0.6. Список круговой: угол = wrap(i − p)·шаг в [−n/2, n/2), кейс 12 стоит слева от кейса 1, ход всегда по короткой дуге; после фильтра (n·шаг < 180°) — открытая дуга с тем же шагом. Боковые рамки тихие (бордер lime .3), фронтальная горит (`::before`: бордер .95 и плотное свечение 18px — широкий блюр в 24 поворачивающихся слоях стоил кадров; меняется только opacity, 150 мс `--ease-out`); у боковых иллюстрация и текст на .45 (названия читаются), фронтальная и (на точном указателе) наведённая — полностью; таблица фактов — жест наведения/фокуса только фронтальной. Подписи иллюстраций в кольце — HTML поверх арта (SVG `<text>` под поворачивающимся предком Blink перекладывает каждый кадр), сам SVG-текст скрыт. Отражение — второе кольцо из 12 стоек (`.arena__ghost`: путь рамки, штрих и заливка гаснут вниз общими градиентами, 60 % высоты карточки; без маски и группового opacity — с ними всё зеркало стало бы offscreen-поверхностью каждый кадр); пол — радиальное свечение и светящийся обод по основанию (статичный SVG через проекции цилиндра, перерисовка на ресайз), сверху один мягкий свет без линий (`.arena__spot`, радиальные градиенты; лучи и линии потолка убраны по просьбе владельца). Отрисовка: карточки и стойки стоят статично (`rotateY(слот·шаг) translateZ(R)`, пишется при перестроении; на замкнутом кольце слот перескакивает на ±n, пока карточка ребром сзади), крутятся только контейнеры, и всегда анимацией, не инлайн-стилем (анимированный transform обновляет дерево свойств компоситора напрямую, инлайновый заново раскладывает слои каждый кадр): у каждого кольца два вложенных (оба `preserve-3d`) — внешний `.arena__turn` / `.arena__mirror-turn` несёт поворот прокрутки `translateZ(−R) rotateY(−t·шаг)`, внутренний (`<ul>`, кольцо зеркала) — только смещение `rotateY(−o·шаг)`. На одном элементе их не совмещать: анимацию главного потока на элементе, чью scroll-linked анимацию ведёт компоситор, Chrome считает, но не рисует (тест «what reaches the screen» проверяет это и по кадрам CDP screencast). И мгновенный программный переход (`jumpPage` в `arena.ts`) пишет компенсирующее смещение в той же задаче, что и `scrollTo`: отложенное до следующего кадра оно может разминуться с коммитом, который несёт компоситору новую прокрутку, и один кадр кольцо стоит уже в цели с пустой половиной слотов (тест проверяет смещение прямо в задаче клика). Где есть ScrollTimeline — это scroll-linked WAAPI-анимация на пришпиленном диапазоне, её ключевые кадры и есть зоны покоя: кольцо крутит компоситор вместе с прокруткой, главный поток только следит (фронтальная карточка, слоты, заголовок); программный переход и перетаскивание поворачивают внутренний контейнер на смещение (приостановленная анимация), которое гаснет к 0 (lerp 0.12 за кадр). Без ScrollTimeline rAF-цикл крутит `currentTime` приостановленной анимации, p догоняет t с той же инерцией (`data-arena-drive` = scroll | loop). Прокрутка — единственный источник истины: сцена пришпилена (`position: sticky`, высота `100svh − nav`), секция прокручивается на 180px на кейс (`.cases__track`, ≥ 360px, пересчёт при каждом перестроении с переякорением на ту же карточку), t = detent(raw) — каждая карточка стоит 45 % своего отрезка, между ними smoothstep. Скрипт никогда не двигает страницу сам (никакой докрутки); если прокрутка остановилась между карточками (200 мс покоя), кольцо само доворачивает смещением к ближайшей за 300 мс ease-out — страница стоит, фронтальная карточка, счётчик и заголовок следуют за ней, а со следующей прокруткой смещение плавно гаснет. Навигация внутри пина — полоса тиков, ←/→/Home/End, клик по боковой карточке, возврат фокуса из шторки, `#case-N`, отпускание перетаскивания — мгновенный `scrollTo` (прыжок не виден за пришпиленной сценой, кольцо доезжает), плавный — только чтобы въехать в пин. Перетаскивание — только в пине, страница стоит: кольцо идёт за указателем (120px на кейс, по кругу на замкнутом кольце, резинка ×0.2 у концов дуги), на отпускании карточка по инерции и один мгновенный скролл; клик после перетаскивания гасится, `touch-action: pan-y`; нажатие — scale .98 за 140 мс, отпускание — та же анимация назад. Клавиатура и AT: roving tabindex — в Tab только кнопка фронтальной карточки, ←/→/Home/End переводят фокус и кольцо, возврат фокуса из шторки делает ту карточку табстопом; клик без указателя (detail 0) по любой карточке открывает её шторку (кольцо доворачивает за ней), указателем по боковой — поворот, по фронтальной — шторка, в пути — только пункт назначения. Заголовок слева внизу (`aria-hidden`): `↳` + название меняются один раз, когда кольцо встало на новую карточку (200 мс fade с .35 + подъём 8px `--ease-out`), в пути не пустеют; под ним mono-строка «направление · теги» — decode ≈350 мс раз на остановку, никогда на hover; наведение (только после настоящего движения указателя) сразу показывает заголовок той карточки и снимается, как только кольцо поехало. Пагинация (`aria-hidden`, вне Tab): счётчик, полоса тиков — одна цель для указателя (≥ 44px на телефонах, x → ближайший тик, шаг из `--arena-tick`), рамка-маркер (transform 200 мс), итого. Фильтр: уходящие карточки гаснут своим `is-out`, остальные скользят на новые углы 300 мс `--ease-out`; горит ровно одна карточка и одна стойка. Ресайз сохраняет фронтальную карточку, смена высоты от адресной строки телефона p не трогает. Монтирование отложено (idle после load или за 1.5 экрана до секции), сразу — при фрагменте в URL или восстановлении позиции; длина арены резервируется заранее (`.is-arena-pending`: сцена в экран, трек по длине), так что монтаж ничего ниже не сдвигает. Без JS, под `prefers-reduced-motion` и в слишком низком окне — обычная сетка, как была (классы `is-arena` не вешаются).

## Безопасность (кратко)
- Никаких секретов в репозитории; `.env*` в `.gitignore`.
- Серверная валидация (zod), лимит частоты запросов, honeypot, проверка Origin, общие тексты ошибок наружу.
- Пользовательский текст никогда не вставляется как HTML (ни на странице, ни в сообщениях в Telegram/почту).
